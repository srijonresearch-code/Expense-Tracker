# Expense-Tracker

A simple command line expense tracker built using Python.

## Features
- Add expense
- View expenses
- View total spent
- View total number of expenses
- Delete expense
- Clear all expenses

## Technologies Used
- Python
- JSON for data storage

## How to Run

1. Clone the repository
2. Run the program

python main.py<br>
